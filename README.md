# passlibs

Sentence-shaped passphrases, Mad Libs style: "adventurous aardvark gracefully juggling
teapots". Easy to read aloud, easy to type on a phone.

Work in progress; the design is in
[docs/superpowers/specs/2026-11-10-passlibs-design.md](docs/superpowers/specs/2026-11-10-passlibs-design.md).
