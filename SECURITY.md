# Security policy

phraselibs makes passphrases that people use to sign in, so a weakness in how it picks words,
or a bit count that overstates the strength, is a security problem.

## Reporting

Please report privately through this repository's **Security** tab ("Report a
vulnerability"), not in a public issue. You'll get a reply within a week.

## Supported versions

The latest release. Fixes are released as a new version; tags are never moved.
